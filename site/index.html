Veja seus agentes de IA trabalhando num escritório em pixel art

Cada sessão do Claude Code ou do Codex ganha uma mesa. Você vê quem está digitando, lendo, pedindo sua permissão ou tomando café, e responde pelo navegador.

Abrir a demo Instalar em 3 comandos

Claude Code · Codex · Docker · Node 22+ · MIT

Tudo o que os agentes fazem, num lugar só

O escritório lê os eventos do Claude Code e do Codex e transforma cada um num gesto, num balão ou num pedido para você.

Atividade ao vivo

Quem trabalha fica sentado digitando, lendo ou rodando comandos. Quem termina recosta, levanta e vai para o café.

Aprove sem trocar de janela

Pedidos de permissão e perguntas do agente aparecem na ficha. Você aprova, recusa com motivo ou responde, e a sessão continua.

Agentes que conversam

O agente principal passa a tarefa ao subagente, que leva o resultado até a mesa quando termina. No tempo livre, eles batem papo.

Terminal da ficha

Diffs coloridos, comandos com cores de sintaxe, respostas em markdown e horário em cada linha. Expande para a tela toda.

Uso e custo do dia

As janelas de 5 horas e semanal do plano, mais tokens e custo por projeto, direto da linha de status do Claude Code.

Um escritório por projeto

Sete temas: Laboratório, Café, Biblioteca, Garagem, Estação espacial, Jardim e Fliperama. Cada projeto ganha a sua sala.

Como funciona

Tudo roda na sua máquina. Nenhum dado sai dela.

  1. 01 Claude Code · Codex Os hooks do Claude Code e o notify do Codex avisam cada evento.
  2. 02 Hooks HTTP Instalados no seu settings.json, sem apagar os hooks que você já tem.
  3. 03 Coletor no Docker Um servidor Node sem dependências em localhost:8420.
  4. 04 O escritório A página no navegador, atualizada em tempo real.

Um terminal que dá vontade de ler

A ficha de cada agente mostra o que ele fez e o que está fazendo agora, com o texto chegando enquanto ele escreve.

  • +Edições como diff, com linhas removidas e adicionadas
  • +Respostas formatadas, com blocos de código e botão de copiar
  • +Rolagem que respeita a sua leitura, com aviso de novas linhas
  • +Interromper e encerrar sessões abertas pelo escritório

Instalar

Depois de instalar, as sessões que você abrir aparecem sozinhas no escritório.

Requisitos

  • Docker
  • Node.js 22+
  • Claude Code ou Codex

Para tirar, rode node hooks/install-claude-hooks.mjs --remove, node hooks/install-codex-notify.mjs --remove e docker compose down: os hooks do escritório saem e os seus continuam.

Terminal · Windows, macOS e Linux 
# 1. baixe o projeto
git clone https://github.com/OWNER/orquestra-office
cd orquestra-office

# 2. suba o coletor e instale os hooks
docker compose up -d --build
node hooks/install-claude-hooks.mjs
node hooks/install-codex-notify.mjs

# 3. abra o escritório
http://localhost:8420

Em breve, um comando só vai fazer tudo isto. Por enquanto, instale pela aba Docker.

  1. instala os hooks do Claude Code e o notify do Codex, com backup das suas configurações
  2. sobe o coletor só na sua máquina, em localhost:8420
  3. abre o escritório no navegador

Seus dados ficam com você

O coletor guarda só o necessário para desenhar o escritório. Por padrão, ele só aceita conexões da sua própria máquina.

No disco

Pasta do projeto, id da sessão, nome da ferramenta, nome do arquivo sem o caminho, o primeiro termo do comando e os totais de tokens e custo.

Só na memória

O texto dos seus pedidos, os comandos completos e as respostas. Nada disso vai para o disco, e tudo some quando o container reinicia.

Só no localhost

Escuta em 127.0.0.1. Abrir na rede local, para usar no celular, é opcional e explícito.
